# Problem Statement

## Cafe Billing System

Design and develop a basic **Cafe Billing System using Python** that accepts the quantity of different food items ordered by a customer and calculates the total bill.

The system should calculate the cost of each item based on its quantity and fixed price. If the total cost of the order is greater than ₹1000, the system should provide a **10% discount**.

After applying the discount, the program should calculate **9% SGST** and **9% CGST** and display the final amount payable by the customer.

### Requirements

The program should:

1. Accept the quantity of burgers, pizzas, pastas, fries, and cokes.
2. Use predefined prices for each item.
3. Calculate the cost of each individual item.
4. Calculate the total cost of the order.
5. Apply a 10% discount when the total cost exceeds ₹1000.
6. Calculate 9% SGST and 9% CGST.
7. Calculate the final payable amount.
8. Display a properly formatted cafe bill.

### Programming Concepts

The project should demonstrate the use of:

* Variables
* Assignment statements
* Input and output
* Arithmetic operators
* Conditional statements (`if-else`)

### Objective

The objective of this project is to understand how basic Python programming concepts can be combined to solve a real-world billing problem.
